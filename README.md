# Мои ассистенты · OTP Space

Интерактивный прототип управления ассистентами по макетам Figma. Версия 25 от 3 ноября 2026 года; история изменений — в папке `notes/`.

## Запуск

Скачайте или клонируйте репозиторий, откройте его папку в терминале и запустите:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000 в браузере. Сборка и установка зависимостей не требуются.

## Возможности

- Добавление ассистентов и настройка названия и срока полномочий.
- Состав заявок и доступность прав — по таблице «Набор возможных прав» БТ; две роли (Ассистент SMT / Ассистент), переключение `?role=assistant` или панель ⌘⇧S.
- Строка «Все заявки» с мастер-переключателями колонок и счётчиками, раскрывающиеся группы, построчные переключатели, подсказки у недоступных прав.
- Меню действий «···» в панели ассистента (редактировать, приостановить, дублировать, удалить) с подтверждениями.
- Сохранение изменений и предупреждения при отмене и выходе без сохранения.
- Дублирование полномочий нескольким сотрудникам с подтверждением замены существующих настроек; срок заполняется отдельно для каждого.
- Приостановление, возобновление и удаление с подтверждением.

Каждое открытие или обновление страницы начинает исследование с нуля: список ассистентов пустой. Изменения сохраняются только в памяти открытой страницы. Серверной части и подключения к HR-системам нет.

## Файлы

- `index.html` — страница прототипа.
- `app.js` — интерактивные сценарии.
- `base.css`, `app.css` — стили.
- `assets/` — локальные изображения, иконки и шрифты.
